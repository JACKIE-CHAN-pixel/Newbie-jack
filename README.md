# Club Event Planner — Session 1

Your mission: make a small event board your own, catch a capacity bug, and leave a Git history that tells the story.

From this folder, run `python planner_demo.py` to see four registration decisions. Run `python planner_demo.py board` to see the event names and free spaces. Each run starts fresh because the demo stores data in memory.

Start with `docs/demo-output.md` if an output surprises you. Follow the steps in `06-git-lab.md` from the Session 1 pack.
